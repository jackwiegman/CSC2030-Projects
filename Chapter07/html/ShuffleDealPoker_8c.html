void dealHand ( unsigned int wDeck[][FACES],
unsigned int hand[][2] )

Deal the top HANDSIZE cards and put them in hand deck.

Loops through deck finding card 1 through HANDSIZE then assigns the row and column (representing suit and face) that the card was found in to the next place in the hand array, filling the array with a new hand of HANDSIZE cards.

Parameters
wDecka 2d unsigned integer array of cards in the deck
FACESa constant integer representing the number of faces in the deck.
handa 2d integer array of size [HANDSIZE][2] representing the cards in the hand.

Loops through hand to print each card to console. Loops through each "card", represented as an index of the hand array. Each card is an array of two integers representing a corresponding index in the wSuit and wFace arrays. These indexes contain the name and face of the card.
